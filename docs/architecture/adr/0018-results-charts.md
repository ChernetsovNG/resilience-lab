# ADR 0018. Графики результатов: свой компонент, виды в раскладке, сводные ряды

Дата: 2026-11-01\
Статус: принято\
Связано: [дизайн графиков результатов](../../superpowers/specs/2026-11-01-results-charts-design.md); [ADR 0011](0011-type-outputs.md); [формат артефакта](../../results-format.md)

## Контекст

Пять графиков интерфейса написаны по отдельности: два на recharts, три на своей разметке SVG. Общего курсора, палитры и подсказок нет. Таймлайн обходит ограничения recharts: прозрачный слой с вручную подогнанными отступами, свои полосы состояния, своё прореживание. Пользователю нужно сравнивать несколько вариантов на одном графике с устойчивыми цветами, сохранять наборы графиков вместе с примером и видеть линию по всем повторениям, а не по одному.

## Решение

1. **Свой компонент `Chart` на SVG** рисует все графики по описанию: ось X (время, параметр перебора или выход элемента — график «Y от X»), ряды (элемент, выход каталога, вариант, повторение), раскраска, наложения, шкала, пресет. recharts удаляется после перевода последнего графика.
2. **Цвет — по устойчивому ключу**: вариант по месту в эксперименте, элемент и показатель по идентификатору. Одна палитра на весь интерфейс, переопределения по правилам.
3. **Виды хранятся в разделе `views` документа раскладки**: представление, а не модель. Варианты выбираются правилом, неизвестные идентификаторы пропускаются.
4. **Ядро пишет сводную часть рядов** по каждому варианту и точке. Для счётчиков и долей это среднее и полуширина 95 % CI по повторениям, для квантилей — квантиль слитого скетча окна и min–max квантилей повторений. Вычислитель выходов каталога появляется в ядре; совпадение с web закреплено контрактным тестом.

## Последствия

- Наведение, курсор и масштаб общие для всех графиков с одной осью X.
- Артефакт растёт на 20–30 % при 10 повторениях и меньше при большем числе; Таймлайн по умолчанию грузит одну часть вместо N.
- Формулы выходов вычисляются в двух местах, ядре и web; контрактный тест обязателен при каждом новом выходе.
- Экспорт графика (PNG, SVG) и данных (CSV) делается в браузере из уже загруженных рядов, без отдельного API.
- Свободная компоновка, страница «Результаты» и режим разницы добавляются без пересмотра решения.

## Рассмотренные варианты

- **Обёртка над recharts.** Меньше своего кода для осей, но общий курсор и полосы по-прежнему поверх библиотеки, а компактные графики либо остаются отдельными, либо тянут recharts.
- **uPlot или ECharts.** uPlot умеет общий курсор и полосы, но рисует на canvas (сложнее тестировать и делать доступным), требует новой зависимости и всё равно своей привязки к видам и стилям.
- **Виды в отдельном документе.** Чище по ответственности, но повторяет кодек, схему, API, список файлов и каскады переименования, которые уже есть у раскладки.
- **Сводная линия в браузере по всем повторениям.** Без изменения ядра и с одним вычислителем, но грузит в N раз больше данных: 5 вариантов × 30 повторений упираются в кэш рядов.
