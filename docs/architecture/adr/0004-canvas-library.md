# ADR 0004. Холст редактора на React Flow

Дата: 2026-10-27  
Статус: принято  
Связано: [целевая архитектура](../2026-10-27-target-architecture.md), решение A9; [исследование библиотеки холста](../../research/2026-10-27-canvas-library.md) (#4); [продуктовое видение](../../product/2026-10-27-product-vision.md), §5.5–5.7.

## Контекст

UI переходит на раскладку в стиле draw.io с палитрой, историей действий, правкой на схеме, результатами на схеме, воспроизведением прогона, частицами-запросами и вложенными составными блоками. Исследование #4 сравнило семь библиотек и проверило прототипами React Flow и X6.

## Решение

1. Холст остаётся на `@xyflow/react` (React Flow) для этапов 1–2.
2. Платные Pro-примеры React Flow не используются: история действий, копирование, свёртка и правка подписей пишутся в приложении через открытые API.
3. Предметная модель не зависит от формата библиотеки холста: сценарий, раскладка и состояние воспроизведения хранятся раздельно, а данные React Flow строятся из них.
4. История действий работает на уровне модели: правка модели и раскладки — одна пользовательская операция; перетаскивание не пишет запись на каждый пиксель; воспроизведение в историю не попадает.
5. Воспроизведение управляется единым курсором симуляционного времени: цвет, подписи и положение частиц вычисляются из него, поэтому пауза и перемотка дают тот же кадр.
6. Иерархия (§5.7) — предметная логика приложения: провал внутрь показывает текущий уровень и хранит путь для хлебных крошек; разворачивание подсистемы на месте сохраняет граничные связи.

## Последствия

- Миграции холста нет; существующие компоненты, unit- и E2E-тесты продолжают работать.
- Объём собственной логики редактора — главный риск: история составных действий, копирование со сменой идентификаторов, свёртка подсистем с сохранением портов.
- Выбор пересматривается при воспроизводимом ограничении React Flow на нужном сценарии или если оценка собственной логики редактора окажется дороже переноса на X6 или maxGraph; перед миграцией нужен прототип этого ограничения в тех же условиях.

## Рассмотренные варианты

- **AntV X6** — бесплатные палитра, история, буфер обмена и редактор подписи связи; дороже перенос, больше бандл и выше нагрузка на главный поток в прототипе.
- **maxGraph** — готовые группировка и навигация по вложенности; императивная модель вместо React-компонентов, перенос дороже.
- **JointJS, Rete.js** — открытые ядра, но ключевые операции редактора либо платные, либо пишутся самостоятельно.
- **tldraw** — исключён: для продакшена нужен лицензионный ключ.
- **Excalidraw** — инструмент рисования на canvas, а не редактор вычислимого графа.
