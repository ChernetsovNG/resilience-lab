# Эталоны вида

Эталоны вида элементов интерфейса: что должно получиться и в каких пропорциях. Это не файлы, которые использует приложение, — значки и картинки интерфейса лежат в `web/src/assets/` (правило в [web/AGENTS.md](../../web/AGENTS.md)).

Эталоны рисуются для проекта, а не копируются из чужих источников: репозиторий публичный, а сторонние изображения связаны своими лицензиями. Нотация-ориентир для силуэтов блоков — [C4](https://c4model.com/) (§4.3 [концепции интерфейса](../product/2026-10-29-interface-concept.md), «Вид блока на схеме — по типу»).

| Файл | Что | Главное |
|---|---|---|
| [person.svg](person.svg) | Клиент: фигура «Person» C4 | Голова диаметром ~38 % ширины тела, по центру, нижней третью скрыта за телом — без зазора. Тело — «плечи»: верхние углы со скруглением ~25 % ширины, нижние как у остальных карточек. Голова и тело одного цвета заливки и рамки, текст — внутри тела. |
