# Язык интерфейса

`en.json` и `ru.json` содержат тексты веб-интерфейса. Язык выбирается через
«Вид → Язык» / «View → Language». Явный выбор сохраняется в `localStorage`
под ключом `resilience-lab.language`. Без сохранённого выбора используется
первый поддерживаемый язык из `navigator.languages`: `ru` или `en`, в том
числе региональные варианты вроде `ru-RU` и `en-US`. Если ни один язык не
поддерживается, используется английский. При недоступном хранилище выбор
действует до перезагрузки страницы.

Перевод охватывает кнопки, меню, подсказки, подписи графиков, диалоги,
сообщения доступности, состояния заданий и тексты каталога типов. Названия,
которые ввёл пользователь, идентификаторы, пути и коды диагностики
сохраняются в исходном виде. Сообщения сервера переводятся по коду и
структурированным аргументам; если перевода или аргументов не хватает,
показывается исходный текст. Числовые значения документов и API,
значения перечислений вроде `fixed` и `exponential-full-jitter`, символы
единиц в редактируемых значениях и содержимое артефактов также сохраняются.
Подписи выбора для этих перечислений переводятся, значения в документах
остаются прежними. Язык
интерфейса хранится в браузере и не входит в документы рабочей области.

## Добавление и проверка переводов

Добавляйте ключ одновременно в оба JSON-файла. Имена подстановок вида
`{variant}` должны совпадать; их порядок может различаться. Пользовательские
данные передавайте через подстановки, чтобы перевод не менял их содержимое.
В разработке и тестах неизвестный ключ или недостающая подстановка вызывают
ошибку. В production неизвестный ключ отображается как есть, а для нового
статуса задания показывается его значение из API.

Для текстов `/catalog` используются стабильные пути:

- `catalog.options.<value>` для подписей значений перечислений;
- `catalog.assumptions.<index>`;
- `catalog.types.<typeId>.title` и `.description`;
- `catalog.types.<typeId>.assumptions.<index>`;
- `catalog.types.<typeId>.params.<parameterPath>.title` и `.description`,
  включая вложенные поля, например `call.params.backoff.base.title`.

Новый тип, параметр или допущение сначала добавляется в каталог ядра.
Обновите полный снимок API из корня репозитория:

```sh
./gradlew :apps:cli:installDist
apps/cli/build/install/cli/bin/cli catalog > web/src/test/catalog.json
```

Затем добавьте соответствующие тексты в оба языка. В `en.json` тексты
каталога должны совпадать с ответом API. `catalogs.test.ts` проверяет
равенство ключей и подстановок, а также наличие переводов для всех типов,
допущений, вложенных параметров и их значений выбора в снимке. Запуск из `web`:

```sh
npm test -- --run src/i18n/catalogs.test.ts
```

## Глоссарий

В подписях параметров число не склеивается с существительным. Используется
форма «название: значение», например «обработчики: 4 · очередь: 16».

| English | Русский |
| --- | --- |
| Handlers | Обработчики |
| Queue capacity | Ёмкость очереди |
| Processing time | Время обработки |
| Timeout | Таймаут |
| Attempts | Попытки |
| Backoff | Пауза перед повтором |
| Retry budget | Бюджет повторов |
| Circuit breaker | Предохранитель вызовов |
| Open circuit breaker | Разомкнутый предохранитель вызовов |
| Fallback | Заглушка |
| Readiness check | Проверка готовности |
| Outlier detection | Вывод неисправных экземпляров |
| Fault | Отказ |
| Deadline | Дедлайн |
| Arrival rate | Интенсивность запросов |
| Utilization | Загрузка |
| Mean queue | Средняя очередь |
| Queue rejections | Отказы очереди |
| Amplification | Усиление |
| Orphaned attempts | Брошенные попытки |
| Success rate | Доля успешных |
| Replications | Повторения |
| Warm-up | Разогрев |
| Measurement | Измерение |
| Findings | Выводы |
| Timeline | Таймлайн |
| Problems | Проблемы |
| Assumptions | Допущения |
| Summary | Итог |
| Time | Время |
| Estimate | Оценка |
| Run | Запустить |
| Stop run | Остановить прогон |
| Expand results | Развернуть результаты |
| Save | Сохранить |

Обозначения `p50`, `p95`, `p99`, `RPS` и `CI` сохраняются. Отображаемые единицы
`ms`, `s`, `min`, `KiB`, `MiB` в русском интерфейсе записываются как `мс`, `с`,
`мин`, `КиБ`, `МиБ`. В английском интерфейсе сохраняется прежнее написание.
